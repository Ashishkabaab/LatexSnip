LaTeX Snip — Privacy Policy

Last updated: July 2026

LaTeX Snip is a Chrome extension that converts screenshots of mathematical expressions into LaTeX using a vision AI provider of your choice. This policy explains what data the extension handles and how.

What data LaTeX Snip handles

API keys. When you enter an API key in the extension's Settings page, that key is stored locally on your device using Chrome's built-in chrome.storage.local API. It is never transmitted to any server operated by LaTeX Snip, and it never leaves your device except in the API request described below.

Screenshot data. When you drag a selection over part of your screen, LaTeX Snip captures that region as an image and sends it directly to the AI provider you have chosen (Anthropic, OpenAI, or Google) to generate LaTeX. This image is sent solely for the purpose of math recognition. LaTeX Snip does not store, log, or retain any copy of the image.

What LaTeX Snip does NOT do

  • Does not collect or transmit your API key to any third party other than the AI provider you have selected
  • Does not collect any personal information, browsing history, or usage statistics
  • Does not use cookies or any form of tracking
  • Does not have a backend server — all logic runs locally in your browser except for the API call to your chosen AI provider
  • Does not share any data with advertisers or analytics services

Third-party AI providers

Depending on which provider you select in Settings, your screenshot is sent to one of the following services. Each has its own privacy policy governing how it handles API requests:

  • Anthropic (Claude): anthropic.com/privacy
  • OpenAI (GPT-4o): openai.com/policies/privacy-policy
  • Google (Gemini): policies.google.com/privacy

LaTeX Snip has no control over how these providers handle data once it is received. Please review their respective policies before use.

Permissions

LaTeX Snip requests the following Chrome permissions:

  • activeTab / scripting: Required to inject the drag-select overlay onto the page you are viewing so you can draw a selection box around a math expression.
  • storage: Required to save your provider preference and API key locally on your device.
  • host permissions (<all_urls>): Required because the extension must be able to inject the selection overlay onto any webpage the user is viewing, regardless of the domain.

Changes to this policy

If this policy changes materially, the "Last updated" date above will be revised. Continued use of the extension after any changes constitutes acceptance of the updated policy.
